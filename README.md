# 1984（大洋國一日）

Canvas 像素冒險。靈感來自喬治·歐威爾《一九八四》。

## 遊玩

免費《一九八四》短篇劇情遊戲，電腦或手機瀏覽器即可遊玩：
https://otterbooklover.github.io/1984/

- 手機單檔：下載 [`android.html`](./android.html)，用瀏覽器開啟

操作：WASD／方向鍵、E／空白鍵、虛擬搖桿與互動鍵。右上角可切換中／英文與音樂開關。

## 內容簡述

你已經讀過《一九八四》。現在，請親自走進大洋國，過一回溫斯頓的一天：電幕盯着你，廣場上有人起哄，紀錄部的工作等着你——每一步選擇，都像是你自己做的，直到你發現，這一日從來都不屬於你。

歡迎遊玩後留言分享：你最後有沒有對着電幕說出那句話？若尚未看過我的影片或原著，亦可先體驗大洋國的一日。

希望大家喜歡🙂。
