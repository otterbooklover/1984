# 1984（大洋國一日）

Canvas 像素冒險。靈感來自喬治·歐威爾《一九八四》。

## 遊玩

- Web（推薦）：https://otterbooklover.github.io/1984/
- 手機單檔：下載 [`android.html`](./android.html)，用瀏覽器開啟

操作：WASD／方向鍵、E／空白鍵、虛擬搖桿與互動鍵。右上角可切換中／英文與音樂開關。

## 本地預覽

```bash
python3 -m http.server 8768
```

然後開啟 http://127.0.0.1:8768/

## 內容簡述

你已經讀過《一九八四》。現在，請親自走進大洋國，過一回溫斯頓的一日：電幕盯着你，廣場上有人起哄，走廊盡頭是紀錄部的工作，而每一步選擇，都像是你自己做的——直到你發現，這一日從來都不屬於你。

這是一款短篇像素冒險，用陰沉的氛圍與互動對白，讓你親身體驗極權下的日常：監視、恐懼、懷疑，以及那句你終將說出口的話。
