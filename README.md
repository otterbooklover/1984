# 1984（大洋國一日）

Canvas 像素冒險。靈感來自喬治·歐威爾《一九八四》。

## 遊玩

- Web（推薦畀觀眾）: https://otterbooklover.github.io/1984/
- 手機單檔: 下載 [`android.html`](./android.html) 用瀏覽器開啟

操作：WASD／方向鍵、E／空白鍵、虛擬搖桿與互動鍵。右上角可切換中／英文與音樂開關。

## 本地預覽

```bash
python3 -m http.server 8768
```

然後開啟 http://127.0.0.1:8768/

## 內容簡述

線性流程（看似可選）：房間 → 門廳 → 走廊 → 紀錄部 → 食堂 → 廣場（兩分鐘仇恨）→ 新語 → 日記 → 草原 → 舊貨鋪 → 密房 → 奧勃良寓所 → 《兄弟團》之書 → 拘捕 → 友愛部 → 房101 → 栗樹咖啡館。結局固定「他愛老大哥」。

音樂與音效為 Web Audio 程序生成的陰沉低音氛圍（離線可用）。
